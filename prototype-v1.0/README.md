# 人生の選択と運命の波 - プロトタイプ v1.0

## 概要
* 人生の2択の選択とタイミングが大きな差を生むシミュレーションゲーム。
* 30秒間で運命の風（3秒ごとの自動移動）と5回の主体的選択（キーボード操作）を通じて、最終的な幸福度を体験するプロトタイプ初期完成版。

## 特徴
* 9本の周期運動バー（振幅35px〜80px、上下運動の可視化縞模様）
* 制限時間30秒、自動移動3秒間隔、任意移動5回（← / → キー）
* スタート地点を基準としたリアルタイム幸福度計算と軌跡ライン描画
* 画面外インジケーター（▲ 高みへ / ▼ 底へ）
* 最終リザルト評価とリプレイ機能

## 起動方法
ブラウザで直接 `index.html` を開くことで動作します。
